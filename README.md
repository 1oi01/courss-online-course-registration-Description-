# Cours's – Online Course Registration System

## Project Overview
Cours's is a web-based course registration system developed as an academic project for IT361 – Web Development II.

The system allows students to browse professional technology courses, submit enrollment requests, and manage enrollment records through a database-connected website.

## Technologies Used
- HTML5 & CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Key Features
- Browse and search available technology courses
- View course descriptions, prices, levels, and durations
- Submit course enrollment requests
- Validate form inputs using JavaScript
- View enrollment history
- Edit and delete enrollment records
- Perform CRUD operations using PHP and MySQL
- Demonstration registration and login forms

## Database
The project uses a MySQL database containing two main tables:
- `courses`
- `enrollments`

## How to Run
1. Install XAMPP.
2. Copy the project files into a folder named `courss_project` inside `htdocs`.
3. Start Apache and MySQL.
4. Open phpMyAdmin and import `database.sql`.
5. Visit `http://localhost/courss_project/index.php`.
