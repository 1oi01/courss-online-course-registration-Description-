Cours's - Online Course Registration System

Project theme:
- Website name: Cours's
- Main colors: navy and pink
- All visible Arabic terms were translated into English.
- Currency is shown as SAR.

Main pages:
1. index.php - Home page
2. register_login.php - Register and login page with JavaScript validation
3. courses.php - Course listing page with SELECT query and JavaScript search output
4. enroll.php - Course enrollment page with JavaScript validation and INSERT query
5. history.php - Enrollment history page with SELECT query
6. edit_enrollment.php - Update enrollment page with UPDATE query
7. delete_enrollment.php - Delete enrollment page with DELETE query

Database tables:
1. courses
2. enrollments

How to run the project in XAMPP:
1. Copy the folder courss_project into the htdocs folder.
2. Open XAMPP and start Apache and MySQL.
3. Open phpMyAdmin.
4. Import database.sql.
5. Go to this link in the browser:
   http://localhost/courss_project/index.php
